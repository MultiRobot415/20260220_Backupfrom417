# TELLO Double Control

このプロジェクトは、ステーションモードで接続された2機のTelloドローンをキーボード操作によって同時に制御するためのプログラムです。複数のTelloドローンに対して、単一のキーボードインターフェースから同期した指示を送信することができます。

## 必要条件

- Python 3.6以上
- pygame
- opencv-python
- netifaces
- netaddr

## インストール方法

```bash
pip3 install pygame opencv-python netifaces netaddr
```


## 使用方法

### 1. ドローンのWiFi設定

ドローンをステーションモード（WiFiルータに接続するモード）に設定します：

1. まず、PCをTelloのWiFiに直接接続します
2. 次に、設定スクリプトを実行します：

```bash
python3 ref/formation_setup_tello2.py
```

> 注意: 別のWiFiルータを使用する場合は、スクリプト内のSSIDとパスワードを変更してください。

### 2. メインプログラムの実行

ドローンがWiFiルータに接続された後、メインプログラムを実行します：

```bash
python3 src/tello_double_control.py
```

> 重要: 必ず Python3 で実行してください。

## ドローン検出方法

プログラムは`tello_manager.py`を使用してネットワーク内のTelloドローンを自動的に検出します：

- ローカルネットワークのサブネットをスキャンし、Telloドローンを見つけます
- 応答があったドローンに自動的に接続します
- 検出したドローンは`custom_tello.py`で定義された`CustomTello`クラスで管理されます

## キー操作

- **Q**: 全てのドローンを離陸
- **E**: 全てのドローンを着陸
- **W/S**: 上昇/下降
- **A/D**: 左右回転
- **矢印キー上/下**: 前進/後退
- **矢印キー左/右**: 左右移動
- **ESC**: 緊急停止
- **SPACE**: プログラム終了

> 注意: キーを離すと自動的にホバリングモードに切り替わります。

## 制御パラメータ

プログラム内で以下の制御パラメータが設定されています：
- **SPEED**: 50 (移動速度、0~100で設定)
- **ROTATION_SPEED**: 50 (回転速度、0~100で設定)
- **INTERVAL**: 0.05秒 (コマンド送信間隔)

> 注意: Tello SDKには「xcm移動」といった絶対移動コマンドも存在しますが、本プログラムでは相対的な傾斜角度による制御を採用しています。制御方式が異なるため挙動が大きく変わることに留意してください。

## 注意事項
- ドローンの操作は実験フィールド内で行ってください
- 複数ドローン操作の際、飛行中に徐々に位置関係が変わるので留意すること
- バッテリー残量に注意してください（20%以下での飛行は非推奨）
- 緊急時はESCキーを押して緊急停止してください
- プログラムは必ずPython3で実行してください
- WiFiルータに接続する前に、必ず`formation_setup_tello2.py`で設定を行ってください
- WiFi干渉が多い環境では通信が不安定になる可能性があります
- 推奨動作環境：WiFiルーターから20m以内
- キーを離すと自動的にホバリングする機能を搭載しています
- プログラム終了時はスペースキーを押すと安全に終了します
- 2機飛行の場合は，プログラム開始後のログを見て，2機接続が完了したことを確認してから離陸させてください(ただし，1機しか接続していなくても離陸自体は可能です)
- まれに1機しかコマンドを受けなくなる可能性がありますが，プログラム再実行により解決されることが多いので淡々と再実行してください

## カスタムTelloクラスについて

このプロジェクトでは、DJIの公式SDKではなく、独自に実装した`custom_tello.py`を使用しています。これにより、Python3ベースで複数のドローンを同時に制御(かつ傾斜角度を指示)することが可能になっています。元ネタはmultiTelloformationとDJITellopyです。

## 最新機能

### 自動ホバリング機能
キーを離した瞬間に自動的にホバリングモードに切り替わります。これにより、ドローンが安定した飛行を維持できます。

### 安全な終了処理
スペースキーを押すとプログラムが安全に終了します。終了時には以下の処理が行われます：
- 飛行中の場合は全てのドローンを着陸させる
- 全てのソケット接続を閉じる
- リソースを適切に解放する

また、プログラムが予期せず終了した場合でも、安全な終了処理が行われるように改良されています。

## パフォーマンス特性

- **コマンド送信頻度:** 20Hz（50ms間隔）
- **最大レイテンシ:** 100ms
- **最大同時制御ドローン数:** 理論上は無制限、実用的には2〜4機
- **必要帯域幅:** 約1Mbps/ドローン（ビデオストリーミングを含む場合）

## 将来の拡張性

このシステムは以下の方向に拡張可能です：

1. **ドローン数の増加**
   - ネットワーク帯域幅とルーターの能力に依存
   - コード修正は最小限で対応可能

2. **追加機能**
   - カメラフィードの表示と処理
   - 自動飛行パターン
   - 障害物検出と回避

3. **代替制御インターフェース**
   - ゲームパッド対応
   - 音声コマンド
   - プログラム可能な飛行シーケンス
