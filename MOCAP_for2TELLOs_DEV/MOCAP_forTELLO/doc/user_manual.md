# Tello MOCAP Control - 取扱説明書

## 概要

このプログラムは、OptiTrackモーションキャプチャシステムからの位置フィードバックを使用して、Telloドローンを指定位置でホバリングさせるシステムです。キーボード操作でドローンを制御し、キー入力がない場合は自動的に指定位置（デフォルトではx=0m, z=0m, y=1m）でホバリングします。

## システム構成

- **ハードウェア要件**：
  - Telloドローン
  - OptiTrackモーションキャプチャシステム
  - モーションキャプチャマーカー（ドローンに取り付け）

- **ソフトウェア構成**：
  - `tello_mocap_control.py`: メインプログラム
  - `mocap_stream.py`: モーションキャプチャデータ受信用モジュール
  - `NatNetClient.py`: OptiTrackのNatNetプロトコルクライアント
  - `tello_manager.py`: Telloドローン管理クラス
  - `KeyPressModule.py`: キーボード入力検出モジュール
  - `custom_tello.py`: Telloドローン制御用カスタムクラス
  - `programsforcheck/mocap_continuous.py`: モーションキャプチャデータの継続的受信用サンプルプログラム
  - `programsforcheck/test_tello_only.py`: Telloドローンのみのテスト用プログラム

## セットアップ手順

### 1. 必要なライブラリのインストール

```bash
pip install pygame psutil
```

以下の標準ライブラリも使用します：
- socket
- threading
- struct
- time
- gc（ガベージコレクション制御）

### 2. モーションキャプチャシステムの設定

1. OptiTrackのMotiveソフトウェアでリジッドボディを作成し、IDを設定
2. データストリーミングを有効化（NatNetストリーミングプロトコル。VIEW⇒DataStreaming、チェックボックス押下）
3. `tello_mocap_control.py`内の以下の設定を環境に合わせて変更：
   - `RIGID_BODY_ID`: モーションキャプチャで設定したリジッドボディID
   - モーションキャプチャサーバーのIPアドレス（`initialize_mocap()`関数内）
   - ローカルPCのIPアドレス（`initialize_mocap()`関数内）

   現在の設定：
   ```python
   # MOCAP PCのIPアドレス
   mocap_client.set_server_address("192.168.11.2")
   
   # ローカルPC(Ubuntu，ドローン制御用)のIPアドレス
   mocap_client.set_local_address("192.168.11.13")
   ```
   
   IPアドレスの確認方法：
   - Windows: コマンドプロンプトで `ipconfig` を実行
   - Mac: ターミナルで `ifconfig` を実行
   - Linux: ターミナルで `ip addr` または `ifconfig` を実行

### 3. Telloドローンの準備

1. Telloドローンを充電し、電源を入れる
2. PCをTelloが接続している無線LANルータに接続（事前準備が必要．まだ実施していない場合はTELLO_double_proto/preparation/formation_setup_tello2.pyを実行すること）

## 使用方法

### プログラムの実行

**メインプログラムの実行：**
```bash
python3 src/tello_mocap_control.py
```

**MOCAPデータのみのテストモード（ドローンなし）：**
```bash
python3 src/tello_mocap_control.py --mocap-only
```
> このモードではドローンへの接続を行わず、MOCAPデータの受信とスレッド処理のみをテストします。MOCAPシステムの動作確認やデータ受信のテストに便利です。

**モーションキャプチャデータ受信テスト：**
```bash
python3 src/programsforcheck/mocap_continuous.py
```

> 注意: 必ず Python3 で実行してください。

### キー操作

- **Q**: 離陸
- **E**: 着陸
- **W/S**: 上昇/下降
- **A/D**: 左右回転
- **矢印キー上/下**: 前進/後退
- **矢印キー左/右**: 左右移動
- **ESC**: 緊急停止（強制終了）
- **スペースキー**: 正常終了（全スレッドを適切に終了）

## 動作の仕組み

1. **初期化フェーズ**：
   - モーションキャプチャシステムに接続
   - Telloドローンを検出して接続
   - Pygameウィンドウを初期化（キーボード入力用）

2. **制御フェーズ**：
   - キーボード入力があれば、その指示に従ってドローンを制御
   - キーボード入力がない場合は、モーションキャプチャからの位置情報を使用して自動ホバリング
   - PID制御により、目標位置（デフォルト: x=0m, y=1m, z=0m）を維持

3. **終了フェーズ**：
   - スペースキーを押すと正常終了処理を実行（推奨）
   - ESCキーを押すと緊急停止処理を実行
   - プログラム終了時に、ドローンを安全に着陸
   - 全スレッドを適切に終了し、各種リソースをクリーンアップ

## 座標系について

モーションキャプチャの座標系は右手系で、以下のように定義されています：
- **X軸**: 前後方向
- **Y軸**: 上下方向
- **Z軸**: 左右方向

特に上下方向がY軸であることに注意してください。

## 制御パラメータの調整

`tello_mocap_control.py`内の以下のパラメータを調整することで、制御性能を変更できます：

```python
# 制御パラメータ（デフォルト値）
SPEED = 50  # 移動速度
ROTATION_SPEED = 50  # 回転速度
INTERVAL = 0.05  # コマンド送信間隔
PID_GAIN = 20.0  # PIDゲイン（位置制御用）
```

## トラブルシューティング

### モーションキャプチャシステムに接続できない場合

1. IPアドレスの設定を確認
2. ファイアウォールの設定を確認
3. OptiTrackのMotiveソフトウェアでデータストリーミングが有効になっているか確認

### メインスレッドが終了してしまう場合

1. `mocap_continuous.py` を使用してモーションキャプチャデータの受信状況を確認
2. デバッグレベルを上げて詳細な情報を確認（`DEBUG_LEVEL=2` または `3`）
3. メモリ使用量が大きい場合はガベージコレクションの間隔を短く設定（`GC_INTERVAL=50`）

### ドローンに接続できない場合

1. PCがTelloのWi-Fiネットワークに接続されているか確認
2. Telloのバッテリー残量を確認
3. Telloを再起動して再試行

### 位置制御が不安定な場合

1. PID_GAINの値を調整（小さくすると応答が穏やかに、大きくすると応答が速くなる）
2. モーションキャプチャのマーカー配置を確認
3. 環境内の反射物を取り除く

## シャットダウン手順

プログラムを適切に終了させるための手順は以下の通りです：

### 推奨終了方法（スペースキー）

1. スペースキーを押して正常終了を開始します
2. プログラムは以下の手順で終了処理を行います：
   - ドローンが飛行中の場合は着陸させます
   - 全スレッドに終了シグナルを送信します
   - 各スレッドが適切に終了するのを待機します
   - ソケット接続を閉じます
   - ログファイルを閉じます
3. プログラムが正常終了したことを確認します

### 緊急停止（ESCキー）

緊急時にのみ使用してください：

1. ESCキーを押すと緊急停止が実行されます
2. ドローンは即座にモーターを停止します（落下の可能性あり）
3. プログラムは強制終了されます

### プログラム終了後の確認

プログラムが正常に終了したか確認する方法：

1. ログファイルに「プログラムが正常終了しました」と表示されていることを確認
2. エラーメッセージが表示されていないことを確認
3. ドローンが安全に着陸していることを確認

## 注意事項

- ドローンの操作は広い空間で行ってください
- バッテリー残量に注意してください（20%以下になると警告が表示されます）
- 緊急時はESCキーを押して緊急停止してください
- 初めて使用する場合は、低い高度から始めることをお勧めします
