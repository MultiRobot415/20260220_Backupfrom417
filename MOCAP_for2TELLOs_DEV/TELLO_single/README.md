## 概要
    TELLO_singleはTELLOの単機操作用の基本セットです(Wifi親機モードにのみ対応なので,TELLO複数操作用にWifiルータに接続する設定にしている場合はTELLO_double_protoを使用してください．)
## 構造
    Tello_KeyControl1.pyがメインファイル
    KeyPressModule.pyを読み込んでキーボード操作
## 使い方
    TELLOの電源ON
Wi-fiでTELLOと接続してからTello_KeyControl1.pyを実行してください

## キーボード操作
    q：離陸
    e：着陸

    上矢印：前進
    下矢印：後進
    左矢印：左移動
    右矢印：右移動

    a：左回転
    d：右回転

    w：上昇
    s：下降
