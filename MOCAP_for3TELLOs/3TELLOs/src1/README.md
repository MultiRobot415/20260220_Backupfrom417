# 3機のTello EDUドローン手動制御プログラム

3機のTello EDUドローンをキーボードで手動制御するシンプルなプログラムです。

## 概要

本プログラムは、3機のTello EDUドローンを同時に制御できる手動操作システムです。MOCAPシステムは使用せず、完全手動操作のみを提供します。

### 主な特徴

- **3機同時制御**: 最大3機のドローンを同時操作
- **個別選択機能**: 各ドローンを個別に選択して操作可能
- **シンプルな操作**: キーボードのみで直感的に操作
- **リアルタイム状態表示**: バッテリー残量や飛行状態を表示

## システム要件

- Python 3.x
- pygame
- 3機のTello EDUドローン
- WiFi接続環境

## インストール

### 依存ライブラリのインストール

```bash
pip install pygame
```

## 初期設定

### ドローンIPアドレスの設定

プログラムを実行する前に、`custom_tello.py`の既知のIPアドレスを実際のドローンのIPアドレスに変更してください。

**ファイル**: `custom_tello.py`（280行目付近）

```python
# 既知のIPアドレス（3機対応）
known_tello_ips = ["192.168.11.15", "192.168.11.14", "192.168.11.30"]  # XX部分を実際のIPに変更
```

**重要**: 3号機のIPアドレス（`192.168.11.XX`）を実際の値に変更してください。

## 使用方法

### 1. プログラムの実行

```bash
cd src1
python manual_control_3tellos.py
```

### 2. Pygameウィンドウをアクティブ化

プログラムが起動したら、表示されるPygameウィンドウをクリックして、キーボード入力を有効にしてください。

### 3. ドローンの操作

キーボードでドローンを操作します。

## 操作方法

### 基本操作

| キー | 動作 |
|------|------|
| **Q** | 全ドローン同時離陸 |
| **E** | 全ドローン同時着陸 |
| **ESC** | 緊急停止 |
| **SPACE** | プログラム終了 |

### ドローン選択

| キー | 動作 |
|------|------|
| **1** | ドローン1を選択 |
| **2** | ドローン2を選択 |
| **3** | ドローン3を選択 |
| **0** | 全ドローンを選択（デフォルト） |

### 手動操作（選択されたドローンのみ）

| キー | 動作 |
|------|------|
| **↑** | 前進 |
| **↓** | 後退 |
| **←** | 左移動 |
| **→** | 右移動 |
| **W** | 上昇 |
| **S** | 下降 |
| **A** | 左回転 |
| **D** | 右回転 |

## 使用例

### 基本的な飛行シーケンス

1. プログラムを起動: `python manual_control_3tellos.py`
2. Pygameウィンドウをクリックしてアクティブ化
3. **Q**キーで全ドローン離陸
4. 矢印キーで移動操作（デフォルトは全機同時）
5. **1**キーでドローン1のみ選択
6. ドローン1を個別に操作
7. **0**キーで全機選択に戻る
8. **E**キーで全ドローン着陸
9. **SPACE**キーでプログラム終了

### 個別制御の例

```
1. Qキーで全機離陸
2. 1キーでドローン1を選択
3. 矢印キーでドローン1を前進
4. 2キーでドローン2を選択
5. 矢印キーでドローン2を後退
6. 3キーでドローン3を選択
7. 矢印キーでドローン3を右移動
8. 0キーで全機選択
9. Eキーで全機着陸
```

## 状態表示

プログラム実行中、5秒ごとに以下の情報が表示されます：

```
--- ドローン状態 ---
★ ドローン1: 飛行中, バッテリー: 85%
★ ドローン2: 飛行中, バッテリー: 82%
★ ドローン3: 待機中, バッテリー: 90%
選択: 全機
-------------------
```

- **★**: 現在選択されているドローン
- **飛行中/待機中**: ドローンの飛行状態
- **バッテリー**: バッテリー残量（%）

## トラブルシューティング

### ドローンが見つからない

**症状**: "エラー: ドローンが見つかりませんでした"と表示される

**解決方法**:
1. ドローンの電源が入っているか確認
2. WiFi接続を確認
3. `custom_tello.py`のIPアドレス設定を確認
4. ファイアウォール設定を確認

### キーボード入力が効かない

**症状**: キーを押してもドローンが反応しない

**解決方法**:
1. Pygameウィンドウをクリックしてアクティブ化
2. ウィンドウが最前面にあることを確認
3. "Keyboard Status: OK"と表示されているか確認

### 一部のドローンだけ接続できる

**症状**: 3機中1機または2機しか接続できない

**解決方法**:
1. 接続できないドローンのIPアドレスを確認
2. `custom_tello.py`の`known_tello_ips`配列を確認
3. 各ドローンと個別にpingテストを実施

## 安全上の注意

1. **飛行前の確認**
   - 周囲に人や障害物がないことを確認
   - 十分な飛行スペースがあることを確認
   - バッテリー残量を確認（推奨: 30%以上）

2. **飛行中の注意**
   - 常にドローンの状態を監視
   - バッテリー残量が20%以下になったら着陸
   - 異常な動作があればESCキーで緊急停止

3. **緊急時の対応**
   - **ESCキー**: 即座にモーターを停止
   - 制御不能になった場合は迷わず緊急停止
