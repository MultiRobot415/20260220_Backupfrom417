# mocap_stack
各フォルダ毎に異なる仕様のプログラム群が格納されています．以下それぞれの概要を記載します．
詳細な説明はそれぞれのフォルダ内のREADME.md及びdoc/内のファイルを参照してください．

## フォルダ構成等の共通事項
docs/ は各フォルダ内の詳細説明，技術仕様等をまとめたものです
src/ ソースコードを格納
ref/ 参考実装を格納(githubアップ時は大体消しています)

## MOCAP_for3TELLOs
    3機同時操作用プログラム(MOCAPあり)．MOCAP有の場合はMOCAP位置制御ホバリングとマニュアル操作の切り替えが可能で，無の場合は3機それぞれでマニュアル操作が可能です。フォーメーション制御、故障検出、リーダー交代機能を実装。
    詳細はMOCAP_for3TELLOs/README.mdを参照してください。
    
    **更新履歴**: 2025-11-05 - MOCAP_for2TELLOsをベースに3機対応に拡張完了

## MOCAP_for2TELLOs
    Tello2機によるMOCAP位置フィードバック用プログラム．MOCAPの設定(剛体設定，データストリーミングまで)が適切に行われていることが動作前提となります
## 3TELLOs
    Tello3機同時操作用プログラム(Without MOCAP)．3機同時操作用の参考実装です．これはMOCAP無しで簡易に動作するため，研究室説明等での活用を想定しています(ネットワーク内をスキャンして見つけた順に機体をアサインする仕様となっているため，新たな機体でIPアドレスが変わった場合も気にせず使える一方で実際の機体が入れ違う可能性があります)．
