# MOCAP for 2 TELLOs - フォーメーション制御システム

モーションキャプチャシステム（MOCAP）を用いて2機のTello EDUドローンのフォーメーション制御を実現する高度なドローン制御システム。

## 概要

本プロジェクトは、OptiTrack等のモーションキャプチャシステムからの高精度位置情報を活用し、2機のTello EDUドローンによる**協調フォーメーション制御**を実現します。リーダーフォロワー型の合意アルゴリズムに基づき、横一列フォーメーションでの安定した半自動飛行を可能にします。

### 主な特徴
- **フォーメーション制御**: 横一列、1m間隔の安定した編隊飛行
- **リーダーフォロワーシステム**: 1号機（リーダー）の操作に2号機（フォロワー）が自動追従
- **合意アルゴリズム**: 学術論文に基づく理論的な協調制御
- **リアルタイム制御**: 100ms間隔での高速応答性
- **安全性**: 制御値制限、異常検知、緊急停止機能

## 主な機能

- **協調フォーメーション**: 横一列、1m間隔の安定編隊飛行
- **リーダーフォロワー制御**: 1号機（リーダー）の目標位置変更に2号機（フォロワー）が自動追従
- **合意アルゴリズム**: 論文の式(2)に基づく理論的な協調制御入力

### 基本制御機能

- **自動ホバリングモード (Tモード)**: MOCAP位置情報を用いた精密位置制御
- **手動制御モード**: キーボードによる直接操作
- **連続目標位置制御**: G/B/V/Nキーでリーダーの目標位置を連続的に変更

### データログ・監視機能
- **包括的CSVログ**: 制御データ、MOCAP位置、フォーメーション状態を記録
- **リアルタイムモニタリング**: ドローン状態、バッテリー、位置誤差の表示

### 安全機能
- **制御値制限**: ±20の統一された安全範囲制限
- **緊急停止**: ESCキーで即座停止・着陸
- **異常検知**: 位置データ欠損、制御異常の自動検知
- **フェイルセーフ**: MOCAP接続失敗時の自動手動モード復帰

## 操作方法

### キーボードショートカット

#### 基本操作
- **Q**: 全ドローン同時離陸
- **E**: 全ドローン同時着陸
- **ESC**: 緊急停止（即座停止・着陸）
- **SPACE**: 通常終了（安全なシャットダウン）

#### モード切替（フォーメーション制御連動）
- **T**: 手動モード→**フォーメーション制御モード**に切替
  - 自動ホバリング + フォーメーション制御が同時有効化
  - 2機が横一列（1m間隔）に自動配置
  - 自動モード中は状態維持
- **M**: フォーメーション制御モード→**手動制御モード**に切替
  - フォーメーション制御が自動無効化
  - 手動モード中は状態維持

#### 手動モードの操作
- **矢印キー**: 前後左右移動
- **W/S**: 上昇/下降
- **A/D**: 左右回転
- **1/2**: ドローン選択（1=1号機、2=2号機、その他=両機）

#### フォーメーション制御モード（Tモード）の操作
**リーダー（1号機）の目標位置制御**:
- **G/B**: 前進/後退（X軸方向、ステップサイズ: 0.05m）
- **V/N**: 左右移動（Z軸方向、ステップサイズ: 0.05m）
- **Z**: 目標位置リセット（デフォルト位置に復帰）

**フォロワー（2号機）の動作**:
- リーダーの目標位置変更に自動追従
- 常に1m間隔（Z軸方向）を維持
- 手動操作不要（合意アルゴリズムによる自動制御）

#### 座標系仕様
- **X軸**: 前後方向（+X=前進、-X=後退）
- **Y軸**: 上下方向（+Y=上昇、-Y=下降）
- **Z軸**: 左右方向（+Z=右、-Z=左）

#### フォーメーション制御の特徴
- **連続操作**: キーを押し続けることで連続的な移動が可能
- **スムーズな追従**: フォロワーが遅延なくリーダーに追従
- **安定した編隊**: 合意アルゴリズムによる安定した1m間隔維持
- **制御値制限**: ±20の統一された安全範囲で安定動作
- **1/2**: ドローン1/ドローン2の選択
- **0**: 全ドローン選択

## 🎛️ 重要なパラメータ設定箇所

### キーボード入力・動作速度パラメータ
**ファイル**: `mocap_for_2tellos.py` (115行目付近)
```python
SPEED = 50              # 移動速度（0-100）
ROTATION_SPEED = 50     # 回転速度（0-100）
```
- **SPEED**: G/B/V/Nキーによる移動速度（推奨値: 20-50）
- **ROTATION_SPEED**: H/Kキーによる回転速度（推奨値: 50）

### 制御ゲイン設定（3種類）
**ファイル**: `position_control.py`

#### 1. 基本位置制御ゲイン
```python
self.gain_x = 1.0    # X軸（前後）制御ゲイン
self.gain_y = 1.0    # Y軸（上下）制御ゲイン  
self.gain_z = 1.0    # Z軸（左右）制御ゲイン
self.gain_yaw = 0.2  # ヨー軸（回転）制御ゲイン
```
- **役割**: 目標位置への基本的な位置制御
- **最適化済み**: 個体差を考慮した安定性重視の設定

#### 2. フォーメーション制御ゲイン
```python
self.k1 = 4.0  # 位置誤差補正ゲイン（定常偏差改善）
self.k2 = 2.0  # 速度項補正ゲイン（安定性確保）
```
- **役割**: ドローン間の相対位置制御・編隊維持
- **最適化済み**: 1号機の定常偏差と2号機の振動を同時解決

#### 3. オブザーバーフィードバックゲイン
```python
L_position = 1.0  # 位置フィードバックゲイン
L_velocity = 0.6  # 速度フィードバックゲイン
```
- **役割**: 故障検知のための残差計算・状態推定
- **最適化済み**: 収束性と検知性能のバランス調整

### 故障検知パラメータ
**ファイル**: `observer.py`
```python
fault_threshold = 0.3      # 故障検知しきい値（X-Z平面残差ノルム）
fault_counter_threshold = 1 # 連続検知回数（即座反応）
```
- **検知方式**: X-Z平面特化（水平移動故障に特化、高度変動ノイズ除外）
- **最適化済み**: 水平移動故障への高感度検知と正常時の安定性を両立

## 使用方法

1. 依存ライブラリのインストール
   ```
   pip install opencv-python numpy pygame
   ```

2. MOCAPシステムの設定
   - OptiTrackの場合は、NatNetClientを適切に設定

3. プログラムの実行
   ```
   python src/mocap_for_2tellos.py
   ```

**注意**: モーションキャプチャシステムが接続されていない場合、警告メッセージが表示されますが、手動操作モード（Mモード）での制御は引き続き可能です。この場合、自動ホバリングモード（Tモード）は使用できません。
