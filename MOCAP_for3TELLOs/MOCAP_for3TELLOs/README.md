# MOCAP for 3 TELLOs - 3機のTelloドローンMOCAP制御システム

3機のTello EDUドローンをモーションキャプチャ(MOCAP)システムで高精度に制御するプログラムです。

## 概要

本プログラムは、モーションキャプチャシステムからの位置情報を使用して、3機のTelloドローンを同時に指定位置にホバリングさせることができます。MOCAP接続時は自動ホバリング制御が可能で、MOCAP未接続時でも手動操作が可能です。

### 主な機能

- **3機同時MOCAP制御**: 3機のドローンを高精度に位置制御
- **自動/手動モード切替**: Tキーで自動ホバリング、Mキーで手動操作に切替
- **フォーメーション制御**: リーダーに対してフォロワーが一定の相対位置を保持
- **故障検出とリーダー交代**: 故障を検出して自動的にリーダーを交代
- **個別ドローン選択**: 1/2/3/0キーで各ドローンを個別操作可能
- **CSVログ記録**: 飛行データの詳細記録

## 初期設定

### 1. MOCAPシステムの設定

MOCAPシステム側で以下を設定してください：

1. 3機のドローンに対応する剛体(Rigid Body)を作成
2. 剛体IDを 1, 2, 3 に設定
3. データストリーミングを有効化
4. ストリーミング先IPを制御用PCのIPに設定

### 2. ドローンIPアドレスの設定

`custom_tello.py`の既知のIPアドレスを実際のドローンのIPアドレスに変更してください。

**ファイル**: `src/custom_tello.py`

```python
# 既知のIPアドレス（3機対応）
known_tello_ips = ["192.168.11.XX", "192.168.11.YY", "192.168.11.ZZ"]
```

### 3. リジッドボディIDの確認

`mocap_for_3tellos.py`でリジッドボディIDが正しく設定されているか確認してください。

```python
rigid_body_ids = [1, 2, 3]  # 各ドローンに対応するリジッドボディID
```

### 4. 初期目標位置の設定

必要に応じて初期目標位置を変更してください（座標系: X=前後, Y=上下, Z=左右）。

```python
default_target_positions = [
    [0, 1, 0],  # ドローン1の目標位置
    [0, 1, 1],  # ドローン2の目標位置
    [0, 1, 2]   # ドローン3の目標位置
]
```

## 操作方法

### 基本操作

| キー | 動作 |
|------|------|
| **Q** | 全ドローン同時離陸 |
| **E** | 全ドローン同時着陸 |
| **ESC** | 緊急停止 |
| **SPACE** | プログラム正常終了 |

### モード切替

| キー | 動作 |
|------|------|
| **T** | 自動ホバリングモードに切替（MOCAP必須） |
| **M** | 手動操作モードに切替 |

### ドローン選択

| キー | 動作 |
|------|------|
| **1** | ドローン1を選択 |
| **2** | ドローン2を選択 |
| **3** | ドローン3を選択 |
| **0** | 全ドローンを選択（デフォルト） |

### 手動操作（手動モード時）

| キー | 動作 |
|------|------|
| **↑** | 前進 |
| **↓** | 後退 |
| **←** | 左移動 |
| **→** | 右移動 |
| **W** | 上昇 |
| **S** | 下降 |
| **A** | 左回転 |
| **D** | 右回転 |

### 自動モード時の目標位置操作

| キー | 動作 |
|------|------|
| **G** | 目標位置を前方に移動 |
| **B** | 目標位置を後方に移動 |
| **V** | 目標位置を左に移動 |
| **N** | 目標位置を右に移動 |
| **Z** | 目標位置をデフォルトにリセット |

### 故障検出機能（テスト用）

| キー | 動作 |
|------|------|
| **F** | 故障を注入（テスト用） |
| **R** | 故障を解除 |

## 使用例

### 基本的な飛行シーケンス

1. プログラムを起動: `python3 mocap_for_3tellos.py`
2. Pygameウィンドウをクリックしてアクティブ化
3. MOCAPシステムが接続されていることを確認
4. **Q**キーで全ドローン離陸
5. **T**キーで自動ホバリングモードに切替
6. ドローンが目標位置に自動的に移動
7. **G/B/V/N**キーで目標位置を調整
8. **M**キーで手動モードに戻る
9. **E**キーで全ドローン着陸
10. **SPACE**キーでプログラム終了

### フォーメーション制御のテスト

```
1. Qキーで全機離陸
2. Tキーで自動モードに切替
3. 各ドローンが自動的にフォーメーションを形成
4. Gキーでリーダー(1号機)の目標位置を前進
5. フォロワー(2号機, 3号機)が自動的に追従
```

### 故障検出とリーダー交代のテスト

```
1. Qキーで全機離陸
2. Tキーで自動モードに切替
3. Fキーで1号機に故障を注入
4. システムが自動的にリーダーを2号機に交代
5. 新フォロワー(1号機, 3号機)が新リーダー(2号機)に追従
6. Rキーで故障を解除
```

## トラブルシューティング

### MOCAPに接続できない

**症状**: "モーションキャプチャシステムに接続できませんでした"と表示される

**解決方法**:
1. MOCAPシステムが起動しているか確認
2. データストリーミングが有効になっているか確認
3. ネットワーク設定（IPアドレス、ポート）を確認
4. ファイアウォール設定を確認

**代替策**: MOCAP未接続でも手動モードでの操作は可能

### ドローンが見つからない

**症状**: "ドローンが見つかりません"と表示される

**解決方法**:
1. ドローンの電源が入っているか確認
2. WiFi接続を確認
3. `custom_tello.py`のIPアドレス設定を確認
4. 各ドローンと個別にpingテストを実施

### キーボード入力が効かない

**症状**: キーを押してもドローンが反応しない

**解決方法**:
1. Pygameウィンドウをクリックしてアクティブ化
2. "CLICK THIS WINDOW FOR KEYBOARD FOCUS"の表示を確認
3. ウィンドウが最前面にあることを確認

### 3機のうち一部しか接続できない

**症状**: 3機中1機または2機しか接続できない

**解決方法**:
1. 接続できないドローンのバッテリー残量を確認
2. IPアドレスが正しく設定されているか確認
3. ネットワークスキャンで実際のIPアドレスを確認
4. 1機ずつ順番に接続テストを実施

### 自動モードでドローンが動かない

**症状**: Tキーを押しても自動ホバリングしない

**解決方法**:
1. MOCAPシステムが正常に接続されているか確認
2. リジッドボディIDが正しく設定されているか確認
3. "追跡中のリジッドボディID"にドローンのIDが表示されているか確認
4. MOCAPシステムでドローンが認識されているか確認

## 安全上の注意

### 飛行前の確認事項

1. **環境確認**
   - 十分な飛行スペースがあること（推奨: 3m × 3m以上）
   - 周囲に人や障害物がないこと
   - 床面が滑らかで平坦であること

2. **システム確認**
   - バッテリー残量が十分であること（推奨: 30%以上）
   - MOCAPシステムが正常に動作していること
   - 全ドローンが正常に接続されていること

3. **準備完了の確認**
   - Pygameウィンドウがアクティブになっていること
   - すべてのシステムメッセージを確認したこと

### 飛行中の注意事項

1. **常時監視**
   - ドローンの動作を常に目視で確認
   - バッテリー残量を定期的に確認
   - 異常な動作があれば即座に対処

2. **バッテリー管理**
   - バッテリー残量が20%以下になったら着陸
   - 複数回のフライトを行う場合は充電時間を確保

3. **緊急時の対応**
   - 制御不能になった場合は**ESCキー**で緊急停止
   - 人や障害物に接近した場合は即座に着陸
   - 異常な音や動作があれば即座に電源を切る

## 技術仕様

### 座標系

- **X軸**: 前後方向（正=前進）
- **Y軸**: 上下方向（正=上昇）
- **Z軸**: 左右方向（正=右移動）

### 制御パラメータ

- **制御周期**: 0.1秒 (10Hz)
- **移動速度**: 50 (0-100の範囲で調整可能)
- **回転速度**: 50 (0-100の範囲で調整可能)

### フォーメーション設定

- リーダー: 1号機（デフォルト）
- フォロワー: 2号機（Z軸+1m）、3号機（Z軸+2m）

## 既知の制限事項

1. **MOCAPデータの遅延**: ネットワーク環境により数十ms程度の遅延が発生する可能性
2. **バッテリー駆動時間**: 1回のフライトは約10-15分が目安
3. **通信範囲**: WiFi通信範囲内での動作が必須
