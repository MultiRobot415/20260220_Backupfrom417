# MOCAP_for3TELLOs テスト・動作確認ガイド

## 📋 テスト前の確認事項

### 1. ハードウェア準備

- [ ] 3機のTello EDUドローンのバッテリーが充電されている（推奨: 50%以上）
- [ ] MOCAPシステムが起動している
- [ ] 制御用PCがネットワークに接続されている
- [ ] 十分な飛行スペースが確保されている（推奨: 3m × 3m × 2m以上）

### 2. MOCAPシステムの設定確認

- [ ] 3つの剛体(Rigid Body)が作成されている
- [ ] 剛体IDが 1, 2, 3 に設定されている
- [ ] データストリーミングが有効になっている
- [ ] ストリーミング先IPが正しく設定されている
- [ ] MOCAPソフトウェアで3つの剛体が認識されている

### 3. ソフトウェア設定確認

#### custom_tello.py の既知IPアドレス

```python
known_tello_ips = ["192.168.11.XX", "192.168.11.YY", "192.168.11.ZZ"]
```

**確認方法**:
```bash
# 各ドローンと通信可能か確認
ping 192.168.11.XX
ping 192.168.11.YY
ping 192.168.11.ZZ
```

#### mocap_for_3tellos.py のリジッドボディID

```python
rigid_body_ids = [1, 2, 3]
```

## 🧪 段階的テスト手順

### Phase 1: MOCAPシステム単体テスト

#### 目的
MOCAPシステムが正常に動作し、3機のドローンを認識できるか確認

#### 手順
1. MOCAPシステムのみ起動
2. `mocap_stream_test.py` を実行（存在する場合）
   ```bash
   cd src
   python3 mocap_stream_test.py
   ```
3. 3つのリジッドボディの位置データが正しく表示されるか確認

#### 期待される結果
- 3つのリジッドボディID (1, 2, 3) が追跡されている
- 位置データがリアルタイムに更新される
- データ欠損やエラーが発生しない

---

### Phase 2: ドローン通信テスト（MOCAP無し）

#### 目的
3機のドローンとの通信が正常に確立できるか確認

#### 手順
1. プログラムを通信テストモードで起動
   ```bash
   python3 mocap_for_3tellos.py --mode=comm
   ```
2. 3機すべてのドローンが検出されるか確認
3. バッテリー残量が表示されるか確認

#### 期待される結果
```
ドローン 1 (IP: 192.168.11.XX) に接続しました。バッテリー残量: XX%
ドローン 2 (IP: 192.168.11.YY) に接続しました。バッテリー残量: XX%
ドローン 3 (IP: 192.168.11.ZZ) に接続しました。バッテリー残量: XX%
3機のドローンに接続しました。
```

#### トラブルシューティング
- **一部のドローンが見つからない場合**:
  - ドローンの電源を確認
  - IPアドレスを再確認
  - WiFi接続を確認

---

### Phase 3: MOCAPデータ取得テスト

#### 目的
MOCAPシステムからドローンの位置データが正しく取得できるか確認

#### 手順
1. プログラムをMOCAPテストモードで起動
   ```bash
   python3 mocap_for_3tellos.py --mode=mocap
   ```
2. "追跡中のリジッドボディID"に [1, 2, 3] が表示されるか確認
3. 各ドローンの位置データが表示されるか確認

#### 期待される結果
```
モーションキャプチャシステムに接続しました
追跡中のリジッドボディID: [1, 2, 3]
```

#### トラブルシューティング
- **追跡中のIDが空の場合**:
  - MOCAPシステムでデータストリーミングが有効か確認
  - ネットワーク設定を確認
  - ファイアウォール設定を確認

---

### Phase 4: 手動操作テスト（地上）

#### 目的
キーボード入力が正常に動作するか確認（ドローンは地上）

#### 手順
1. プログラムを起動
   ```bash
   python3 mocap_for_3tellos.py
   ```
2. Pygameウィンドウをクリック
3. 各キーを押して反応を確認:
   - `1`, `2`, `3`, `0` キー: ドローン選択
   - `t`, `m` キー: モード切替
   - 矢印キー、`w`, `s`, `a`, `d` キー

#### 期待される結果
- キーを押すとコンソールにメッセージが表示される
- ドローン選択が正しく動作する
- モード切替が正しく動作する

---

### Phase 5: 離陸・着陸テスト

#### 目的
基本的な離陸と着陸が正常に動作するか確認

#### ⚠️ 重要な安全確認
- 周囲に人がいないこと
- 十分な飛行スペースがあること
- 緊急停止の準備ができていること

#### 手順
1. プログラムを起動
2. `q` キーで離陸
3. 約5秒間ホバリング状態を確認
4. `e` キーで着陸

#### 期待される結果
- 3機すべてが同時に離陸する
- 安定してホバリングする
- 3機すべてが同時に着陸する

#### トラブルシューティング
- **一部のドローンが離陸しない場合**:
  - バッテリー残量を確認
  - 床面が平坦か確認
  - プロペラに異常がないか確認

---

### Phase 6: 手動操作テスト（飛行中）

#### 目的
手動モードでの移動操作が正常に動作するか確認

#### 手順
1. `q` キーで離陸
2. 矢印キーで移動を確認:
   - `↑`: 前進
   - `↓`: 後退
   - `←`: 左移動
   - `→`: 右移動
3. `w`/`s` キーで上下移動を確認
4. `a`/`d` キーで回転を確認
5. `e` キーで着陸

#### 期待される結果
- すべての移動コマンドに正しく反応する
- 動作が滑らかで安定している
- 選択されたドローンのみが動作する（個別選択時）

---

### Phase 7: 個別ドローン選択テスト

#### 目的
各ドローンを個別に選択して操作できるか確認

#### 手順
1. `q` キーで離陸（全機）
2. `1` キーでドローン1を選択
3. 矢印キーでドローン1のみが動くことを確認
4. `2` キーでドローン2を選択
5. 矢印キーでドローン2のみが動くことを確認
6. `3` キーでドローン3を選択
7. 矢印キーでドローン3のみが動くことを確認
8. `0` キーで全機選択
9. 矢印キーで全機が動くことを確認
10. `e` キーで着陸（全機）

#### 期待される結果
- 選択されたドローンのみが動作する
- 選択切替がスムーズに動作する
- 全機選択で全ドローンが同時に動作する

---

### Phase 8: 自動ホバリングテスト（MOCAP必須）

#### 目的
MOCAPによる自動位置制御が正常に動作するか確認

#### 手順
1. `q` キーで離陸
2. `t` キーで自動モードに切替
3. 各ドローンが目標位置に移動することを確認:
   - ドローン1: [0, 1, 0]
   - ドローン2: [0, 1, 1]
   - ドローン3: [0, 1, 2]
4. 約30秒間安定してホバリングすることを確認
5. `m` キーで手動モードに戻る
6. `e` キーで着陸

#### 期待される結果
- ドローンが自動的に目標位置に移動する
- 目標位置で安定してホバリングする
- 位置誤差が±10cm以内に収まる

#### トラブルシューティング
- **ドローンが動かない場合**:
  - MOCAPデータが取得できているか確認
  - リジッドボディIDが正しく認識されているか確認
  - 目標位置が適切な範囲内か確認

---

### Phase 9: 目標位置変更テスト

#### 目的
自動モード中に目標位置を変更できるか確認

#### 手順
1. `q` キーで離陸
2. `t` キーで自動モードに切替
3. `g` キーで目標位置を前進させる
4. ドローンが追従することを確認
5. `b` キーで目標位置を後退させる
6. `v`/`n` キーで左右移動を確認
7. `z` キーで目標位置をリセット
8. `e` キーで着陸

#### 期待される結果
- 目標位置の変更に応じてドローンが移動する
- 移動が滑らかで安定している
- リセット機能が正常に動作する

---

### Phase 10: フォーメーション制御テスト

#### 目的
リーダー・フォロワー型のフォーメーション制御が動作するか確認

#### 手順
1. `q` キーで離陸
2. `t` キーで自動モードに切替
3. フォーメーションが形成されることを確認:
   - ドローン1（リーダー）: [0, 1, 0]
   - ドローン2（フォロワー）: [0, 1, 1]
   - ドローン3（フォロワー）: [0, 1, 2]
4. `g` キーでリーダーの目標位置を変更
5. フォロワーが相対位置を保ったまま追従することを確認
6. `e` キーで着陸

#### 期待される結果
- フォロワーがリーダーに対して一定の相対位置を保つ
- リーダーの移動にフォロワーが追従する
- フォーメーションが崩れない

---

### Phase 11: 故障検出とリーダー交代テスト

#### 目的
故障を検出してリーダー交代が正常に動作するか確認

#### 手順
1. `q` キーで離陸
2. `t` キーで自動モードに切替
3. `f` キーで1号機（リーダー）に故障を注入
4. リーダー交代が発生することを確認
5. 新リーダー（2号機）が旧リーダーの目標位置を継承することを確認
6. 新フォロワー（1号機、3号機）が新リーダーに追従することを確認
7. `r` キーで故障を解除
8. `e` キーで着陸

#### 期待される結果
```
🔄 リーダー交代検出: 1号機 → 2号機
📍 旧リーダー目標位置: [x, y, z]
✅ 新リーダー目標位置継承完了: [x, y, z]
```

#### 評価ポイント
- リーダー交代が検出される
- 新リーダーが目標位置を継承する
- フォーメーション制御が継続される
- システムが安定して動作し続ける

## 🐛 よくある問題と解決方法

### 問題1: MOCAPデータが取得できない
**症状**: "追跡中のリジッドボディID: []"と表示される

**確認事項**:
1. MOCAPシステムでデータストリーミングが有効になっているか
2. ネットワーク設定が正しいか
3. ファイアウォールがブロックしていないか
4. 剛体IDが1, 2, 3に設定されているか

### 問題2: 一部のドローンが反応しない
**症状**: 3機中1機または2機しか動作しない

**確認事項**:
1. バッテリー残量が十分か
2. IPアドレスが正しく設定されているか
3. WiFi接続が安定しているか
4. プロペラが正常に回転しているか

### 問題3: 自動モードで位置がずれる
**症状**: 目標位置に到達せず、ドリフトする

**確認事項**:
1. MOCAPシステムの精度が適切か
2. リジッドボディが正しく認識されているか
3. 制御パラメータが適切か
4. 環境（気流等）の影響がないか

### 問題4: リーダー交代が動作しない
**症状**: Fキーを押しても交代しない

**確認事項**:
1. 自動モード(Tモード)になっているか
2. observer.pyの設定が正しいか
3. 信頼度しきい値の設定が適切か
