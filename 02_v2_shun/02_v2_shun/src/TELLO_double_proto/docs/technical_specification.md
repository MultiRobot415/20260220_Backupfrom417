# Tello Double Control - 技術仕様書

**作成日:** 2025-06-26  
**バージョン:** 1.0

## 1. 概要

Tello Double Controlは、複数（主に2機）のDJI Telloドローンを同時に制御するためのPythonアプリケーションです。このシステムは、ステーションモード（WiFiルータ経由の接続）で動作する複数のTelloドローンに対して、単一のキーボードインターフェースから同期した指示を送信することができます。

## 2. システムアーキテクチャ

### 2.1 コンポーネント構成

システムは以下の主要コンポーネントから構成されています：

1. **メインコントローラ (`tello_double_control.py`)**
   - ユーザー入力の処理
   - ドローン制御ロジックの実装
   - 複数ドローンの同期制御

2. **Telloマネージャ (`tello_manager.py`)**
   - 利用可能なTelloドローンの検出
   - 複数ドローンの管理
   - ドローンへの接続管理

3. **カスタムTelloクラス (`custom_tello.py`)**
   - 標準Tello SDKの拡張
   - 通信プロトコルの実装
   - ドローン固有の機能へのアクセス

4. **キーボード入力モジュール (`KeyPressModule.py`)**
   - キーボード入力の検出
   - 入力イベントの処理

### 2.2 通信フロー

```
[ユーザー] → [キーボード入力] → [メインコントローラ] → [Telloマネージャ] → [カスタムTelloクラス] → [ドローン]
```

## 3. 技術仕様

### 3.1 通信プロトコル

- **プロトコル:** UDP
- **ポート:** 8889（コマンド）、8890（ステータス）、11111（ビデオストリーム）
- **通信形式:** テキストベースのコマンド（ASCII）
- **タイムアウト:** 8秒（デフォルト）

### 3.2 制御コマンド

システムは以下のTello SDK v2.0コマンドを使用します：

| コマンド | 説明 | パラメータ |
|---------|------|-----------|
| `command` | SDKモード有効化 | なし |
| `takeoff` | 離陸 | なし |
| `land` | 着陸 | なし |
| `emergency` | 緊急停止 | なし |
| `rc` | リモートコントロール | 左右移動, 前後移動, 上下移動, ヨー回転 |
| `battery?` | バッテリー残量取得 | なし |

### 3.3 RC制御パラメータ

`rc`コマンドは4つの整数パラメータを取ります：

- **a (左右移動):** -100〜100（左〜右）
- **b (前後移動):** -100〜100（後〜前）
- **c (上下移動):** -100〜100（下〜上）
- **d (ヨー回転):** -100〜100（反時計回り〜時計回り）

### 3.4 キーボードマッピング

| キー | 機能 |
|-----|------|
| Q | 離陸 |
| E | 着陸 |
| W | 上昇 |
| S | 下降 |
| A | 左回転 |
| D | 右回転 |
| ↑ | 前進 |
| ↓ | 後退 |
| ← | 左移動 |
| → | 右移動 |
| ESC | 緊急停止 |

## 4. 実装詳細

### 4.1 ドローン検出と接続

1. ネットワークスキャンによる利用可能なTelloドローンの検出
2. 各ドローンへの接続確立
3. バッテリー状態の確認

### 4.2 同期制御メカニズム

1. キーボード入力の検出
2. 移動値の計算
3. スレッドを使用した複数ドローンへの同時コマンド送信
4. 定期的なホバリングコマンド送信（安全機能）

### 4.3 エラーハンドリング

1. 接続エラーの検出と再試行
2. タイムアウト処理
3. 緊急停止機能
4. グレースフルシャットダウン

## 5. パフォーマンス特性

- **コマンド送信頻度:** 20Hz（50ms間隔）
- **最大レイテンシ:** 100ms
- **最大同時制御ドローン数:** 理論上は無制限、実用的には2〜4機
- **必要帯域幅:** 約1Mbps/ドローン（ビデオストリーミングを含む場合）

## 6. 制約事項

1. **WiFi接続の安定性に依存**
   - 干渉が多い環境ではパフォーマンスが低下する可能性あり
   - 推奨最大距離：ルーターから20m以内

2. **バッテリー寿命**
   - 約13分の飛行時間（環境による）
   - バッテリー残量20%以下での飛行は非推奨

3. **同期精度**
   - コマンド実行の同期ずれ：最大100ms
   - 位置ドリフト：時間経過とともに増加

## 7. 拡張性

システムは以下の方向に拡張可能です：

1. **ドローン数の増加**
   - ネットワーク帯域幅とルーターの能力に依存
   - コード修正は最小限で対応可能

2. **追加機能**
   - カメラフィードの表示と処理
   - 自動飛行パターン
   - 障害物検出と回避

3. **代替制御インターフェース**
   - ゲームパッド対応
   - 音声コマンド
   - プログラム可能な飛行シーケンス
