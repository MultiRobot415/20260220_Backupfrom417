# ψ項の振動的挙動の解析と対策

## 1. 問題の定式化

### 1.1 ψの定義（v4_observer.tex）

制御入力における調整項ψは以下のように定義される：

```
ψ_i = -τ_i · (sign(e_{p,i}) - λ_i)
```

ここで：
- `τ_i ≥ 0`: 共線状態の深刻度を示すスカラー
- `sign(e_{p,i}) ∈ [-1,1]³`: 位置誤差の符号関数（Filippov意味）
- `λ_i ∈ ℝ³`: 適応調整項（`||λ_i|| < λ_max < 1`）

### 1.2 観測された現象

シミュレーション結果より、ψが以下のような振動的挙動を示すことが観測される：

1. **高周波振動**: ψの各成分が短時間で急激に変化
2. **不連続性**: sign関数の不連続性に起因する跳躍
3. **持続性**: 収束付近でも振動が継続

---

## 2. 理論的原因の解析

### 2.1 sign関数の不連続性（根本原因）

**Filippov意味での符号関数**:
```
sign(x) = {
    +1    if x > 0
    [-1,1] if x = 0  （集合値）
    -1    if x < 0
}
```

**問題点**:
- `e_{p,i} ≈ 0`の近傍で`sign(e_{p,i})`が`[-1,1]³`の任意の点を取りうる
- 数値計算では`e_{p,i}`が厳密に零にならず、零近傍で振動
- sign関数が`+1`と`-1`を繰り返し切り替わる

**数学的記述**:

位置誤差が`e_{p,i}(t) = ε·sin(ωt)`（εは小さい正数）のように振動すると仮定すると：

```
sign(e_{p,i}(t)) = {
    +1  if sin(ωt) > 0  (0 < t < π/ω, 2π/ω < t < 3π/ω, ...)
    -1  if sin(ωt) < 0  (π/ω < t < 2π/ω, 3π/ω < t < 4π/ω, ...)
}
```

したがって、`ψ_i = -τ_i · (sign(e_{p,i}) - λ_i)`も振動する。

### 2.2 チャタリング現象（Chattering）

スライディングモード制御の文脈で知られる現象：

**定義**: 不連続制御入力により、システムがスライディング面の両側を高周波で往復する現象

**本システムでの発現**:
1. 位置誤差`e_{p,i}`が零近傍に達する
2. sign関数が不連続に切り替わる
3. 制御入力ψが跳躍する
4. 位置誤差が再び零を横切る
5. 1に戻る（繰り返し）

**周波数の推定**:

閉ループ系の固有振動数を`ω_n = √(K_p)`とすると、チャタリング周波数は：
```
ω_chat ≈ √(K_p / ε)
```

ここで`ε`は位置誤差の振幅。`ε → 0`のとき`ω_chat → ∞`（数値計算では打ち切り誤差で有限）。

### 2.3 適応λの影響

適応項`λ_i = -γ·Δv_i`は速度誤差に依存するため：

```
ψ_i = -τ_i · (sign(e_{p,i}) - λ_i)
    = -τ_i · sign(e_{p,i}) + τ_i · λ_i
```

- 第1項: sign関数により振動（不連続）
- 第2項: λ_iにより滑らか

**トレードオフ**:
- λ_iが大きいほど、第2項が第1項の振動を相殺
- しかし、`||λ_i|| < λ_max < 1`の制約により相殺は不完全

## 3. 対策の提案

### 3.1 解析的対策（理論的改善）

#### 対策1: 飽和関数による近似

**修正制御則**:
```
ψ_i = -τ_i · (sat_δ(e_{p,i}) - λ_i)
```

ここで、飽和関数`sat_δ: ℝ³ → [-1,1]³`は：
```
sat_δ(x) = {
    x/δ      if ||x|| ≤ δ  （境界層内）
    x/||x||  if ||x|| > δ  （境界層外）
}
```

**効果**:
- `||e_{p,i}|| ≤ δ`の境界層内で連続化
- チャタリングの抑制
- 境界層幅δを調整パラメータとする

**理論的保証**:
- Lyapunov解析により、最終有界性（ultimate boundedness）が保証される
- 誤差は`O(δ)`の範囲内に収まる

**実装**:
```matlab
function y = sat_delta(x, delta)
    norm_x = norm(x);
    if norm_x <= delta
        y = x / delta;
    else
        y = x / norm_x;
    end
end
```

---

#### 対策2: tanh関数による近似

**修正制御則**:
```
ψ_i = -τ_i · (tanh(k·e_{p,i}) - λ_i)
```

ここで`k > 0`は調整ゲイン。

**効果**:
- C∞級の滑らかな関数（無限回微分可能）
- `k → ∞`のとき`tanh(k·x) → sign(x)`に収束
- kを有限にすることでチャタリング抑制

**特性**:
```
tanh(k·x) ≈ {
    k·x        if |k·x| << 1  （線形領域）
    sign(x)    if |k·x| >> 1  （飽和領域）
}
```

**実装**:
```matlab
function y = tanh_approx(x, k)
    y = tanh(k * x);
end
```

**推奨パラメータ**:
- `k = 10`: 適度な滑らかさとsign関数への近似のバランス
- `k = 100`: よりsign関数に近いが、チャタリングのリスク増加

---

#### 対策3: 適応λの飽和限界の調整

**現在の設定**:
```
||λ_i|| ≤ λ_max = 0.99
```

**提案**:
```
||λ_i|| ≤ λ_max = 0.5 ～ 0.7
```

**根拠**:
- λ_maxを小さくすることで、sign関数の影響が相対的に増加
- チャタリングは悪化する可能性があるが、収束が速くなる
- 逆に、λ_maxを大きくすると滑らかになるが収束が遅延

**トレードオフの定量化**:

Lyapunov関数の微分（v4_observer.tex式参照）:
```
V̇ ≤ -(K_v + τ_i·γ)||e_v||² + τ_i·√3·||e_v||
```

- γが大きいほど減衰項が強化される
- λ_maxは飽和処理に影響するため、間接的にγの効果に影響

---

### 3.2 実装上の対策（見せ方の工夫）

#### 対策A: ローパスフィルタの適用（ポスト処理）

**方法**:
プロット時にψをローパスフィルタで平滑化：

```matlab
% Butterworth低域通過フィルタ
fc = 1;  % カットオフ周波数 [Hz]
fs = 1 / mean(diff(t));  % サンプリング周波数
[b, a] = butter(2, fc/(fs/2));  % 2次Butterworthフィルタ
psi_filtered = filtfilt(b, a, psi_history);

plot(t, psi_filtered);
```

**注意**:
- これは表示のみの工夫で、実際の制御則は変更しない
- フィルタ遅延により実時間での適用は不適切

---

#### 対策B: 移動平均の適用

**方法**:
```matlab
window_size = 50;  % 移動平均のウィンドウサイズ
psi_smooth = movmean(psi_history, window_size);

plot(t, psi_smooth);
```

**効果**:
- 高周波成分を除去
- トレンドを強調

---

#### 対策C: エンベロープ表示

**方法**:
ψの最大値・最小値をプロット：

```matlab
% ウィンドウ内での最大値・最小値を計算
window_size = 100;
psi_max = movmax(psi_history, window_size);
psi_min = movmin(psi_history, window_size);

plot(t, psi_max, 'r--', 'DisplayName', '\psi max');
hold on;
plot(t, psi_min, 'b--', 'DisplayName', '\psi min');
plot(t, psi_history, 'k-', 'Alpha', 0.3, 'DisplayName', '\psi raw');
legend;
```

**効果**:
- 振動の振幅を視覚化
- 収束の様子を明確に表示

---

#### 対策D: RMSプロット

**方法**:
ψのRMS（二乗平均平方根）をプロット：

```matlab
window_size = 100;
psi_rms = sqrt(movmean(psi_history.^2, window_size));

plot(t, psi_rms);
ylabel('||\psi||_{RMS}');
```

**効果**:
- ψのエネルギーを定量化
- 収束の指標として明確

## 5. 理論的考察

### 5.1 チャタリングは問題か？

**制御理論の観点**:
- スライディングモード制御では、理論的にはチャタリングが存在してもスライディング面への収束は保証される
- 実システムでは、アクチュエータの帯域制限によりチャタリングは物理的に実現されない（平均化される）

**本研究での立場**:
1. シミュレーションでは、チャタリングは数値現象として現れる
2. 理論証明（LaSalle-Yoshizawa）では、V̇ ≤ 0の不等式により収束を保証しており、チャタリングの有無は直接影響しない
3. 実機実装では、飽和関数による近似が必須

**結論**:
- **理論的には問題ない**（収束は保証される）
- **実用的には改善が望ましい**（飽和関数の導入）

---

### 5.2 飽和関数導入後の理論的保証

**定理**（最終有界性）:

飽和関数`sat_δ(x)`を用いた制御則により、位置誤差は以下の集合に最終的に収束する：
```
lim_{t→∞} ||e_{p,i}(t)|| ≤ c·δ
```

ここで`c > 0`は定数。

**証明の概略**:

Lyapunov関数の微分を計算すると、
```
V̇ ≤ -K_v·||e_v||² + τ_i·||e_v||·||sat_δ(e_p) - sign(e_p)||
```

境界層外（`||e_p|| > δ`）では、`sat_δ(e_p) = sign(e_p)`であるから、
```
V̇ ≤ -K_v·||e_v||² ≤ 0
```

境界層内（`||e_p|| ≤ δ`）では、`||sat_δ(e_p) - sign(e_p)|| ≤ 1`であるから、
```
V̇ ≤ -K_v·||e_v||² + τ_i·||e_v||
```

この不等式より、`||e_v||`が十分大きければV̇ < 0であり、軌道は有界である。最終的に、誤差は`O(δ)`の範囲内に収まる。□

## 7. まとめ

### 7.1 ψの振動の原因

1. **根本原因**: sign関数の不連続性
2. **誘発要因**: 位置誤差が零近傍で振動
3. **増幅要因**: 数値計算の打ち切り誤差

### 7.2 推奨対策

**解析的対策**: 飽和関数による連続化（境界層幅`δ = 0.1 m`）

**見せ方の工夫**: エンベロープ+RMSプロット

### 7.3 理論的結論

- sign関数を用いても収束は保証される（LaSalle-Yoshizawa定理）
- 飽和関数を用いると最終有界性が保証される（`||e_p|| ≤ O(δ)`）
- チャタリングは理論的には問題ないが、実用的には改善が望ましい
