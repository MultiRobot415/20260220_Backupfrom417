# オクルージョン時の推定器挙動の数学的解析

## 1. v2（オブザーバ型）の理論的挙動

### 1.1 推定器の定義（v4_observer.tex）

```
̇p̂_i = v_i + ξ_i      （式159）
̇v̂_i = u_i + K_obs(v_i - v̂_i)  （式160）
```

ここで：
- `v_i`: **実速度**（IMUなどで直接計測可能）
- `ξ_i`: 相対測定による補正項
- `K_obs > 0`: オブザーバゲイン

### 1.2 オクルージョン時の数学的挙動

**オクルージョン発生時**:
```
Hij = 0, Hik = 0  →  H_ii = 0
B_ff の該当行がゼロ  →  ξ_i = 0
```

**推定器の動作**:
```
̇p̂_i = v_i + 0 = v_i
̇v̂_i = u_i + K_obs(v_i - v̂_i)
```

**位置推定の時間積分**（Assumption 2: p̂_i(0) = p_i(0)）:
```
p̂_i(t) = p̂_i(0) + ∫₀ᵗ v_i(τ) dτ
       = p_i(0) + ∫₀ᵗ v_i(τ) dτ
       = p_i(t)  （定義により）
```

### 1.3 結論

**✅ v2では、オクルージョン時でも位置推定誤差は生じない（理論的に正しい）**

理由：
1. 推定器が**実速度 v_i を直接使用**している
2. v_i は IMU などのオンボードセンサで計測可能（相対測定不要）
3. ξ_i = 0 でも、v_i により正確な積分が可能

## 2. v1（PID型）との比較

### 2.1 v1の推定器（my4thsemi.tex, 式444-448）

```
̇p̂_i = v̂_i                    （推定速度を使用！）
̇v̂_i = -k_p(p̂_i - p_i*) - k_v(v̂_i - v_i) - k_i z_i + ̇v_i* + ξ_i
̇z_i = p̂_i - p_i*
```

**重要な違い**: v1では `̇p̂_i = v̂_i` （推定速度）

### 2.2 v1でのオクルージョン時の挙動

**オクルージョン発生時**:
```
ξ_i = 0
̇p̂_i = v̂_i
̇v̂_i = -k_p(p̂_i - p_i*) - k_v(v̂_i - v_i) - k_i z_i + ̇v_i*
```

**問題点**:
- `̇p̂_i = v̂_i` なので、v̂_i に誤差があると p̂_i にも誤差が蓄積
- ξ_i = 0 のため、相対測定による補正が失われる
- k_v(v̂_i - v_i) の項があるが、これだけでは不十分

**結論**: ❌ v1では、オクルージョン時に推定誤差が蓄積する可能性がある

## 3. 設計思想の違い

| 項目 | v1 (PID型) | v2 (オブザーバ型) |
|------|------------|-------------------|
| 位置推定式 | `̇p̂_i = v̂_i` | `̇p̂_i = v_i + ξ_i` |
| 実速度の使用 | 補正項のみ | 直接積分 |
| オクルージョン耐性 | 低（誤差蓄積） | 高（v_i により維持）|
| 理論的根拠 | PID制御 | 状態オブザーバ |

---

## 4. 実機での意味

### v2の優位性

1. **IMU統合**: 実速度 v_i を IMU で直接計測可能
2. **ロバスト性**: オクルージョン時でも位置推定が維持される
3. **Separation Principle**: 推定器と制御器が分離

### v1の課題

1. 推定速度 v̂_i に依存するため、オクルージョン時に脆弱
2. ξ_i = 0 で補正が失われると、推測航法に退化

---

## 5. ユーザーの期待との乖離

**ユーザーの期待**:
> オクルージョン中、推定値が狂う挙動が期待される

**実際の v2 の挙動**:
> オクルージョン中でも、位置推定は正確（v_i を直接使用）

**理由**:
- ユーザーは v1 型（PID型）の挙動を期待
- v2 は**オブザーバ型**で設計思想が異なる
- v2 の設計は**理論的に正しく、実機での有効性が高い**

---

## 6. 検証すべき点

1. ✅ λ の有効化: τ = 0 のとき ψ = 0 → 正しい
2. ✅ ξ の計算: オクルージョン時 H_ii = 0 → ξ_i = 0 → 正しい
3. ✅ 位置推定: ̇p̂_i = v_i により維持 → 理論的に正しい

## 結論

**v2 の現在の実装は数学的に正しい。**

オクルージョン時に「推定値が狂わない」のは、v2 がオブザーバ型推定器を採用しているためであり、設計意図通りの挙動である。

実機実装において、IMU で v_i を計測できる限り、この設計は**v1 よりも優れている**。
