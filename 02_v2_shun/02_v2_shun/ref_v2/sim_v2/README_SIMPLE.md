# シンプル直線軌道シミュレーション

## 概要

多項式軌道生成の代わりに、**直線軌道**と**一定加速度**を用いたシンプルな目標軌道生成を実装しました。

## 主な特徴

### 1. 直線軌道
- 初期目標位置から最終目標位置まで**一直線**に移動
- 複雑な曲線ではなく、最短経路を移動

### 2. 台形速度プロファイル
```
速度
  ^
  |     ___________
  |    /           \
  |   /             \
  |  /               \
  |_/                 \___
  +---------------------> 時間
    加速  等速   減速
```

- **加速フェーズ**: 一定加速度で加速
- **等速フェーズ**: 最大速度で巡航
- **減速フェーズ**: 一定加速度で減速

### 3. 検証しやすい加速度設定
- デフォルト: `0.1 m/s²`
- 加速時間: `10秒`
- 減速時間: `10秒`

## ファイル構成

### 新規作成ファイル
- **`define_trajectory_simple.m`**: シンプルな軌道設定
- **`main_simple.m`**: シンプル軌道用メインスクリプト
- **`run_simple.bat`**: 実行用バッチファイル

### 既存ファイル（そのまま使用）
- `system_dynamics.m`: 状態方程式
- `calculate_control_logic.m`: 制御ロジック
- `calculate_weight_matrices.m`: 重み行列計算
- `plot_results.m`: 結果可視化

## 実行方法

### 方法1: MATLABから直接実行
```matlab
cd('c:\MATLAB\sim4th_simple')
main_simple
```

### 方法2: バッチファイルから実行
`run_simple.bat` をダブルクリック

## 設定のカスタマイズ

`define_trajectory_simple.m` の以下のパラメータを変更可能：

```matlab
%% 目標軌道パラメータ
cfg.trajectory.type = 'trapezoidal';  % 台形速度プロファイル
cfg.trajectory.accel_time = 10.0;     % 加速時間 [s]
cfg.trajectory.decel_time = 10.0;     % 減速時間 [s]
cfg.trajectory.max_accel = 0.1;       % 最大加速度 [m/s^2]
```

### 加速度を変更する例

#### より速い加速（0.2 m/s²）
```matlab
cfg.trajectory.max_accel = 0.2;
cfg.trajectory.accel_time = 5.0;
cfg.trajectory.decel_time = 5.0;
```

#### よりゆっくりした加速（0.05 m/s²）
```matlab
cfg.trajectory.max_accel = 0.05;
cfg.trajectory.accel_time = 15.0;
cfg.trajectory.decel_time = 15.0;
```

## 出力内容

### コンソール出力
1. **軌道設定情報**
   - 軌道タイプ
   - 加速時間・減速時間
   - 最大加速度

2. **初期設定**
   - 各エージェントの初期位置
   - 目標位置（初期・最終）
   - 移動距離

3. **シミュレーション結果**
   - 実際の軌道長
   - 重み行列の統計情報

### グラフ出力
1. **既存のプロット**（`plot_results.m`）
   - 3D軌跡
   - 追従誤差・推定誤差
   - 速度・制御入力

2. **追加プロット**
   - **目標加速度プロファイル**: 台形プロファイルの確認
   - **目標速度プロファイル**: 速度の時間変化

## 元の多項式軌道との比較

| 項目 | 多項式軌道 | シンプル直線軌道 |
|------|-----------|----------------|
| 軌道形状 | 3次多項式（滑らか） | 直線 |
| 加速度 | 時間変化する | 一定（台形） |
| 境界条件 | v(0)=0, v(T)=0 | v(0)=0, v(T)=0 |
| 検証しやすさ | やや複雑 | **非常にシンプル** |
| 実装 | `define_trajectory.m` | `define_trajectory_simple.m` |

## 検証ポイント

このシンプルな設定により、以下が検証しやすくなります：

1. **加速度の影響**
   - 設定した加速度が正しく反映されているか
   - 加速度プロファイルが台形になっているか

2. **直線追従性能**
   - エージェントが直線経路を追従できるか
   - 目標との誤差がどう変化するか

3. **制御ゲインの調整**
   - `k_p`, `k_d` の効果が明確に観察できる
   - 過渡応答の評価が容易

4. **共線状態からの脱出**
   - シンプルな軌道でも脱出機構が機能するか

## トラブルシューティング

### エラーが出る場合
1. 既存の `system_dynamics.m` などが正しく配置されているか確認
2. MATLABのバージョンが対応しているか確認

### 結果が期待と異なる場合
1. 加速度設定を確認（`cfg.trajectory.max_accel`）
2. 制御ゲインを確認（`cfg.k_p`, `cfg.k_d`）
3. シミュレーション時間を確認（`cfg.t_end`）

## 次のステップ

シンプルな軌道で基本動作を確認したら：
1. 加速度パラメータを変更して挙動を観察
2. 制御ゲインを調整して最適化
3. より複雑な軌道（元の多項式軌道）で性能評価
